# Provenance of the Lean sources

This file lists where each of the 688 Lean source files of this repository (`Challenge.lean`,
`Solution.lean` and every `.lean` file under `Complexity/`, `PT/` and `ArtGallery/`) comes from, as
of 2026-10-31.

Apart from `Challenge.lean` and `Solution.lean`, every file is a copy of the file of the same path
in the author's Palomar entry [AGP]
([PALOMAR-2026-10-27-000025](https://palomar-registry.org/entry?id=PALOMAR-2026-10-27-000025&version=1) v1,
*The Art Gallery Problem is ∃ℝ-complete: point-point, boundary-point and point-boundary variants,
in Lean 4*) or in its development extended by the orthogonal construction, identical except that
comments naming development programs or design notes that are not part of this repository are
reworded (Lean code is unchanged): this repository consists of the modules that the six orthogonal
theorems import, directly or indirectly. The origins below are those recorded for these files in
that development, where they were determined by comparing every file with the files of the source
repositories (exact byte comparison, then a line diff after replacing `Chazelle` by `ArtGallery`).
Line counts are physical lines.

## Sources

* **NPCompleteness-Lean4** — <https://github.com/RBarish-UTokyo/NPCompleteness-Lean4>,
  commit `3e603e795b44fedcf7d6dd65b7d1e30547ead925` (Palomar entry
  [PALOMAR-2026-10-02-000013](https://palomar-registry.org/entry?id=PALOMAR-2026-10-02-000013&version=1) v1,
  *NP-completeness of SAT, 3-SAT and their variants (the Cook–Levin theorem) in Lean 4*),
  Apache-2.0: the machine model (`Complexity/Machine.lean`), P, NP and polynomial-time reductions
  (`Complexity/Classes.lean`), and the modules they and `PT/` depend on. According to that entry,
  its `Complexity` library was written by GPT-6 Astra (OpenAI) and revised and extended by Claude
  Opus 5.5 (Anthropic).
* **Max3SAT-MaxSNP-APX-Lean4** — <https://github.com/RBarish-UTokyo/Max3SAT-MaxSNP-APX-Lean4>,
  commit `10079b2a14bd0df47d2a24364133f6008b9c207f` (Palomar entry
  [PALOMAR-2026-10-09-000010](https://palomar-registry.org/entry?id=PALOMAR-2026-10-09-000010&version=1) v1,
  *MaxSNP-completeness and APX-completeness of MAX-3-SAT and 3-OCCURRENCE MAX-3-SAT (the PCP
  theorem and hardness of approximation) in Lean 4*), Apache-2.0 (a later entry of the same
  author, which includes the NPCompleteness-Lean4 library; the files taken from that library are
  byte-identical in both): the polynomial-time framework `PT/` and the register-machine language
  `Complexity/Reg.lean`, `Complexity/Reg/*`. These were written for that entry by Claude Fable 5.1
  and Claude Opus 5.5 (Anthropic). That repository also contains Lean files adapted from the
  OpenAI Math release (its `OAI/` directory); none of them is included or imported here.
* **LinearTimeTriangulation-ChazelleAlgorithm-Lean4** —
  <https://github.com/RBarish-UTokyo/LinearTimeTriangulation-ChazelleAlgorithm-Lean4>,
  commit `92cc7745aa026aad3e80e7a72fe88cfbd909614a` (Palomar entry
  [PALOMAR-2026-10-05-000003](https://palomar-registry.org/entry?id=PALOMAR-2026-10-05-000003&version=2) v2,
  *Linear-Time Triangulation of Simple Polygons (Chazelle's Algorithm) in Lean 4*), Apache-2.0
  (same author): the polygon definitions of its specification and part of its geometric library
  (planar geometry, the Jordan curve theorem for polygons, existence of triangulations and the
  affine-invariance lemmas). The namespace `Chazelle` is renamed to `ArtGallery` throughout, and
  each file carries a provenance note in its module docstring. According to that entry, it was
  written with AI assistance, mainly Claude (Anthropic).

No other Lean code is reused. Mathlib is the only dependency.

## The statement and the solution

* `Challenge.lean` consists of a header, the definitions of `Complexity/Machine.lean` and
  `Complexity/Classes.lean` (definitions only), the definitions of `ArtGallery/Spec.lean` and
  `ArtGallery/Orthogonal/Spec.lean` that the six theorems use, and the theorem statements. It was
  produced from the statement of [AGP] and its orthogonal extension by removing the definitions
  and theorems that do not concern the orthogonal point-point and point-boundary problems, and
  replacing its header.
* `Solution.lean` imports the two modules of the orthogonal theorems.

## Authorship of the new files

All files marked *new* or *generated*, the adaptations of the files marked *adapted*, and the
programs that generated the *generated* files were written with the assistance of Claude Opus 5.5
(Anthropic), under the direction of the author. The generators (programs with exact rational
arithmetic) are not part of this repository. Generated files contain data and certificates that
the Lean kernel checks; apart from their header comments they are as generated.
